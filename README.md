## 加拿大机房解决的是哪一类问题

先把延迟这件事讲清楚，因为它决定你会不会买错。

**加拿大和中国之间没有直连海缆。** 你在温哥华或多伦多放的机器，数据回国的物理路径必然经过美国中转，差别只在于走的是普通国际线路还是优化线路。搬瓦工的第三方实测页把这点说得很直白：即便是电信 CN2 GIA，从加拿大回程也要先经过洛杉矶，这是改不了的物理限制。所以加拿大机房 + CN2 GIA 能做到 150–200ms，已经是这个地区的上限，再往上加钱也换不来香港那种个位数延迟。

具体数字可以拿多伦多机房的第三方实测做对标：全国平均约 232ms，电信约 210ms、联通约 238ms、移动约 251ms、港澳台约 203ms。三网去程都从上海出口，经美国转入加拿大。温哥华走普通线路的机房更差一些，200–280ms，晚高峰丢包会上升；换成 CN2 GIA 的温哥华机房能压到 150–200ms，丢包 1–2%。

也就是说，**加拿大VPS 回国延迟的合理预期是 150–280ms 这个区间**，落在哪一端取决于商家给你的线路档次，而不是配置高低。一台 $2.99 的机器和一台 $170 一年的机器，CPU 差十倍，延迟可能只差 50ms，也可能差 100ms 以上。

Evoxt 官网只标注了国家层面的加拿大区域，没有写明具体城市，也没有公开回国路由的优化说明。如果你的用途对延迟敏感，下单前先找客服确认机房城市，或者先买最小档月付实测一遍再决定要不要加钱升配。需要加拿大 IP 而不在乎那几十毫秒的场景，则可以跳过这一步。

## 三个容易被忽略的成本项

**首期价不等于续费价。** 加拿大商家 4GoodHosting 在价格页上写得很明确：促销价只覆盖新订单的第一个计费周期，之后按划线原价续费，而且折扣不适用于 Plesk、SQL Server 授权和管理服务。这是行业里的常见做法，不代表每家都这样，但意味着你看到任何"首月 $X"的报价，都该去购物车页面确认续费金额。Evoxt 的价格表展示的是标准月付价，没有划线原价和首期折扣字样，预付周期最长可选 3 年；即便如此，下单前在结算页核对一遍实付总额仍是必要的动作。

**同一个城市，线路档次能差三倍价。** 搬瓦工在温哥华有两个机房：普通线路的套餐 $49.99/年，CN2 GIA 的套餐 $169.99/年，物理位置一样，价格差三倍多，而且两个机房分属不同套餐系列，不能通过控制面板互迁，想换线路只能重新买。这条规律适用于所有商家：便宜的档位和优化的档位往往不是同一批机器，也不是同一个价格体系。

## 常见问题

**加拿大VPS 国内延迟多少算正常？**
150–280ms 之间都算正常，具体取决于线路。普通国际线路的温哥华或多伦多机房多在 200–280ms，走 CN2 GIA 的优化线路能压到 150–200ms。低于 150ms 的加拿大机房基本不存在，因为中加之间没有直连海缆。

**联通用户要不要避开加拿大机房？**
多伦多的第三方实测里，联通约 238ms 且丢包比电信、移动略多，部分整理页直接建议联通用户改选洛杉矶或圣何塞节点。这个结论来自第三方测试，不代表所有加拿大机房，但联通用户下单前最好先用商家提供的测试 IP 自己 ping 一遍。

**能解锁 Netflix 加拿大区吗？**
有第三方实测显示，温哥华的原生加拿大 IP 可以完整解锁 Netflix 并识别为加拿大区，YouTube、Google Play、Apple 商店也识别为加拿大。但 Evoxt 官网没有标注 IP 归属类型，是否原生、能否解锁流媒体，官方价格页没有说明。需要这类用途的话，先买最小档月付实测，比看宣传页可靠。

**年付还是月付？**
Evoxt 支持月付起、最长预付 3 年，也支持充值余额自动抵扣。第一次用某家加拿大机房，建议先月付跑一两个计费周期，确认延迟和稳定性符合预期再考虑长周期。年付折扣的前提是你能用完这一年。

**能退款吗？**
Evoxt 的价格页没有列出退款条款，这一点和搬瓦工明确写出的"30 天内全额退款"不同。如果你比较在意退出成本，下单前直接问客服退款政策，或者在结算页确认条款，别默认所有商家都有无条件退款。
